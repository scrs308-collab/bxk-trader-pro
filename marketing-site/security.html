Security

Security is part of the architecture.

BXK Trader Pro is being designed so broker access, user isolation, and execution permissions are explicit parts of the system rather than conveniences added later.

Broker authorization

Where supported, broker connections use OAuth authorization. Broker tokens are associated with the individual BXK Trader Pro user and stored in encrypted form.

Account isolation

Broker connections and selected accounts are scoped per user. The application is designed to fail closed when a user does not have access to the requested broker connection or account.

Execution controls

Account-data access and trade execution are treated as separate capabilities. A broker being available as a data source does not automatically make it an execution broker.

Responsible disclosure

Security information on this page describes the product design and is not a certification, warranty, or guarantee that a security incident cannot occur.

Getting Started

Sign in to BXK Trader Pro

Open app.bxktraderpro.com. The secure sign-in screen contains fields for Username and Password.

  1. Enter your BXK Trader Pro username.
  2. Enter your password.
  3. Select SIGN IN.
  4. If BXK requires a password change, complete that step before continuing.

Chapter 3

Connect Your Broker

Broker connections allow BXK Trader Pro to retrieve supported account and position information. Available brokers depend on your account access and the broker integrations currently enabled.

Tastytrade

  1. Open Position Monitor or the broker controls shown on the dashboard.
  2. Select Connect Tastytrade when the option is available.
  3. Sign in directly with Tastytrade.
  4. Authorize BXK Trader Pro.
  5. If more than one brokerage account is returned, select the account BXK should use.
Your Tastytrade password stays with Tastytrade. BXK uses broker authorization tokens rather than storing your broker password.

Account Data Source vs. Execution Broker

BXK separates the broker used to read account data from the broker used to execute orders. This makes the source of each action explicit.

Tastytrade is the current execution path for supported live order workflows. Schwab integration is designed for account-data access when enabled.

Build a Trade

The Trade Parameters row controls the trade BXK evaluates.

Control Purpose
Underlying Select SPX or enter another supported symbol.
LOAD Loads discovery data for the selected symbol.
Strategy BXK Auto, Iron Condor, Bull Put Credit Spread, or Bear Call Credit Spread.
Expiration Select the desired DTE.
Wing Width Select the distance between spread strikes.
Contracts Select the requested position quantity.

Standard SPX workflow

  1. Confirm SPX is selected.
  2. Choose BXK Auto or a specific strategy.
  3. Choose the expiration.
  4. Choose the wing width.
  5. Choose the number of contracts.
  6. Select BUILD TRADE.
QQQ and other universal underlyings may display OBSERVATION ONLY. When execution is blocked, BXK can analyze the setup without allowing an order to be submitted.

Evaluate the Trade Candidate

When BXK finds a candidate, the Mission Control area displays the proposed trade structure and current trade economics.

Review these fields

Mission Status Whether the current candidate is approved.
Mission Score Trade-quality score for the current setup.
Confidence BXK confidence label for the setup.
Execution READY or BLOCKED.
Credit Proposed net credit.
POP Probability of profit when available.
Max Risk Defined maximum trade risk.
Buying Power Estimated capital requirement.
If BXK does not approve a setup, the card displays Stand Aside or NO TRADE and explains why.

When an approved candidate is available, the action button becomes ENTER TRADE.

Review and Submit an Order

Selecting ENTER TRADE does not immediately send an order. BXK first opens the BXK Order Review window.

Mode banner

The review window clearly identifies whether Trader Pro is operating in LIVE or SAFE mode.

If the banner says BXK LIVE MODE, a successful submission can place a real order at Tastytrade.

Final Risk Check

BXK performs six visible checks before allowing an order to proceed:

  1. Order preview created.
  2. Positive credit.
  3. Maximum risk defined.
  4. Buying power calculated.
  5. All required option legs present.
  6. Execution status ready.

Also review Expiration, DTE, Limit Credit, Probability of Profit, Maximum Profit, Maximum Risk, and Buying Power.

Do not submit a live order merely because BXK checks passed. Confirm the option legs, quantity, expiration, limit price, and risk match the trade you intend to place.

Use Position Monitor

Open Position Monitor to review supported positions returned by your selected broker account.

Position summary

The top of the monitor displays the number of open positions and Total Open P/L. If quote quality is incomplete, BXK may label the value as an estimate.

Position card

OPEN P/L Current estimated or live profit/loss.
PROFIT CAPTURED Progress toward maximum profit.
POSITION STRUCTURE Short and long option legs.
TRADE VALUES Opening credit, current value and risk.

BXK POSITION COACH

The coach may display guidance such as:

HOLD CONSIDER EXIT CLOSE POSITION REVIEW NOW EXPIRATION DAY
A QUOTE QUALITY WARNING means option pricing may be wide or incomplete. BXK may suspend automated P/L exit guidance when valuation quality is unreliable.

Use Trader Pro on Your Phone

BXK Trader Pro uses the same responsive application on desktop and mobile. There is no separate trading application to maintain.

  1. Open app.bxktraderpro.com in your mobile browser.
  2. Sign in with the same BXK account.
  3. Use the same Trade Setup, Position Monitor, Market Summary, Strategies, Performance, and available System tools.
  4. Rotate the phone or scroll horizontally only where a wide table requires additional space.
Position monitoring is particularly useful on mobile because the responsive cards preserve the same P/L, position structure and coach information.

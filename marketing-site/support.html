Support

Help without the scavenger hunt.

Current users

For account or application support, use the support channel provided inside BXK Trader Pro. Do not send brokerage passwords, access tokens, refresh tokens, API secrets, or other credentials in support messages.

Broker connections

If a broker connection expires or is revoked, reconnect through the broker connection controls in BXK Trader Pro. Broker authorization is completed with the broker, not by sending credentials to BXK.

Commercial availability

Public subscription plans are still in development. Broker features may vary by account type and by third-party API approval.
